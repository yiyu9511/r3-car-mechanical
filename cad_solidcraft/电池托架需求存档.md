# 电池托架需求存档（2026-11-09）

> 本文只记录需求与已确认的数据，不含任何 A1–A8 修改模型（已全部删除）。
> 后续如重新设计，以下为唯一依据。

## 1. 任务目标

为 R3 双层小车设计**电池托架（3D 打印件）**，基于用户提供的原始参考件
`exports/ref2_底盘主层板与电池底座.step`（SolidWorks 导出，含「主层板 + 电池底座」两个实体）。
主层板是别人的板，**不要**；只做底座部分的改造。

## 2. 用户确认过的需求（按时间顺序）

1. **删除主层板实体**，成品只留电池托架本体。
2. **托架主体结构不动**：地板、两侧长墙、端墙、腔内定位柱、原有缺口等保持原样。
3. **扎带槽必须贯通**：扎带要能穿过槽把电池绑住。扎带是**绕外围一圈**的，
   所以槽所在的「那一圈」路径上不能有任何其他东西（柱、法兰、凸起都不行）。
4. **删除四角安装耳**（连同耳上的 4×Ø3.4 孔，孔距 26×105）。
5. **耳位改为底部支撑柱**：
   - 柱 Ø7、**高 10 mm**（配 M3×10 螺丝；底盘板厚 1.5 mm）
   - 柱底加**法兰垫**（外扩增大接触面积，提高稳定耐用）
   - 柱内 Ø2.5×7 自攻导向孔（用户选择：**自攻**方案，不做螺母沉孔）
   - **螺丝不能碰到电池架主体**（螺丝尖距主体地板要有余量）
6. **柱位必须对准底盘真实孔位**：后柱 (±43, -128.47)、前柱 (±39.04, -77.33)，
   两排柱要**对称支撑**（托架整体后移让柱位对称，柱相对托架中心 ±25.57 mm）。
7. **槽与柱的关系**：槽不能和柱子在同一个位置——**槽的 Y 范围与柱的 Y 范围完全不能重叠**。
8. **槽方向**：纵向两条（平行长边），X 范围：左 -82.7..-74.6、右 -24..-15.9。
9. **槽的剖面（用户最终澄清，以此为准）**：
   - **在底部切，从底部把底部切薄一点**——不是把底板切空，而是在 X 范围内、Z 方向打薄（留下顶部薄层，约 0.8 mm），
     电池仍坐在连续的底板上；
   - **贯穿 = X 范围固定、Z 打薄、-∞ < y < +∞ 全程为空**——槽沿 Y 方向必须**全程连续**，
     不允许中途断开或被任何结构打断（不能像我之前那样只切 |y|≤30）；
   - **侧壁切穿**：X 范围内对应的侧壁部分也要切透（不被壁挡住）。
10. **供电口**：位置参照原始参考件——左长壁 y≈-41..-23 全高窗口（电池出线口）。
11. **建模顺序**：基础盒 → 开供电口 → 开电池腔 → 加柱 → **最后开扎带槽**。
12. **电池尺寸已卡死**：腔体尺寸不能缩小/改动。

4. **托架主体是否保留原版细节**（内腔定位柱、端墙缺口、台阶）——用户要求"主体不动"，
   但重新建模时哪些必须复刻未逐项确认。

## 5. 过程教训（避免重犯）

- 选孔必须用实体探针（材料体积=0）验证，不能信旧清单或圆角面。
- SolidCraft 0.30.1：`selection.delete` 删实体用 `items:[{"type":"body","name":"..."}]`；
  拉伸 join 仅面贴合会被拒（留 0.1–0.2 mm 嵌入）；薄层短距切会静默失败，改用大距离全高切。
- MCP 每个连接是独立设计会话，所有操作须在同一连接内完成；命令走 `batch`/`execute`。
- 扎带槽的"贯通"指**槽本身贯穿**，不是把槽两端封死；槽的路径环上不能有任何结构。
- 用户要的是"按原始参考件的尺寸与开口重建基础盒子"，不是对原 STEP 做布尔手术。

## 6. 最终定案（v7，2026-11-09 用户确认"差不多了"）

文件：`battery_cradle.sc`（SolidCraft 原生，可编辑时间线）/ `exports/battery_cradle.step`（单实体，体积 18487 mm³）。

建模顺序：基础盒 → 供电口 → 电池腔 → 扎带槽（底部打薄 + 端壁切穿）→ 四柱 → 法兰 → 导向孔 → 端部筋沿。

| 特征 | 几何 |
|---|---|
| 基础盒 | 66.6 × 90.6 × 12（x -82.6..-16、y ±45.3、z 61.5..73.5），板 2、壁 2 |
| 供电口 | 左长壁 y -41..-23，自腔底到墙顶全高窗口 |
| 电池腔 | x -80.6..-18、y ±43.3，顶开 |
| 扎带槽 ×2 | 中间两条纵向：x **-63..-55**、**-43..-35**，沿 Y 全程（-∞<y<+∞）；**从底部打薄 1.35，留 0.75 薄层（底板不切穿）** |
| 槽端切穿 | 只把两条槽 X 范围对应的端壁切穿：前端壁与后端壁各 2 个窗口（共 4 个），整段贯透 |
| 四柱 | Ø7×10（z 51.5..61.7），柱位 (-23.73,±43)、(-74.87,±39.04) → 底盘孔 (±43,-128.47)、(±39.04,-77.33) |
| 柱底法兰 | **Ø14×3 圆形**（接触面积 ~154 mm²/柱，是稳定性的关键） |
| 自攻孔 | Ø2.5×7（M3×10 从下穿上，不碰主体，尖距地板 ≥2.3 mm） |
| 端部筋沿 | 两端各 3 段（x -82.6~-63 / -55~-43 / -35~-16），y ±44.9~46.9，z 2mm；跳过扎带窗口，覆盖后柱 |
| 装配变换 | x_world=y_local、y_world=-x_local-152.2、z_world=z_local-50 |

验证（`scripts/verify_cradle.py` + 探针）：单实体、槽 Y 全程无料、槽内底部空且 web 保留、槽 X 范围端壁切穿而窗口外保留、
长侧壁保留、筋沿覆盖后柱、Ø14 法兰存在、柱孔贯通 —— 全 PASS。
