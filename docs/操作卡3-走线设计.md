# 操作卡 3：走线（线缆）设计

> FreeCAD 没有专门的线束工作台，但有成熟够用的办法：
> **Draft 画路径 → Sweep 扫掠成实体 → 参与干涉检查**。

## 一、FreeCAD 里怎么画一根线

### 方法 A：示意线（快，5 秒）

Draft 工作台 → **DWire（多段线）** → 在 3D 里沿要走的路径依次点几个点 → 双击结束。
得到一条空间折线。**只是示意**，不占体积，看走向够用，但做不了干涉检查。

### 方法 B：真实线缆实体（推荐，能参与干涉检查）⭐

1. **Draft → DWire**：沿走线路径点出折线（拐角处多点几个点，后面倒圆角成弯）。
2. 路径太硬？切 **Curves 工作台**（插件管理器装）用 BSpline 过点，得到平滑弧线。
3. **画截面**：在路径起点垂直方向建草图，画一个**圆**，直径 = 线缆实际外径。
4. **Part → Sweep（扫掠）**：先选截面圆，再选路径线 → 确定 → 得到线缆实体。
5. 多根线一起走 = 多扫几根，或画成扁排线/束（用矩形截面更接近扎起来的样子）。

> 关键：**弯曲半径**要够，扫掠时路径拐角太急会自交失败。

## 二、走线设计规则（本项目要遵守的）

| 规则 | 数值/做法 |
|---|---|
| 弯曲半径 | ≥ 4×线缆外径（硅胶软线可小，排线/屏蔽线按 6×） |
| 动力 vs 信号分离 | **电机动力线**与**编码器/航模信号线**分开走；必须交叉时 **90° 垂直交叉**，禁止平行捆扎 |
| 插拔空间 | 端子前留 **≥15mm** 手指空间；端子朝向易达的一侧 |
| 长度余量 | 比实测路径长 **10~20%**，方便拆装维修；别拉紧固定 |
| 应力释放 | 靠近端子处用扎带固定在支架上，别让焊点/端子受力 |
| 扎带固定点 | 每 50~80mm 一个，转角两侧各一个 |
| 避开 | 轮子/悬挂行程范围、编码器、电机散热面、螺丝拆装路径 |

## 三、在装配里验证（关键一步）

1. 把线缆实体插进装配体，用 Joint 或直接定位。
2. **干涉检查**：Part 工作台 → **剖切(Section Cut)** 看内部；
   或插件管理器装 **A2plus / Assembly4 的干涉检查**做批量检测。
3. **拆装顺序演练**：想清楚是先插线再装板，还是反过来——确认线不会被夹住、不会被螺丝压到。
4. 装配体加一个"线缆"组，方便整体隐藏/显示（选中组按空格）。

## 四、产出

- 装机时拿装配截图当接线参考图（比手画靠谱）
- 线缆长度可从扫掠路径**测量**出来（Measure → 选路径线 → 读长度），直接拿去买线/裁线
- 走线路径确定后，设计亚克力板时**在板上预留过线孔/扎带孔**（这一步最容易被漏，回头改板最麻烦）
