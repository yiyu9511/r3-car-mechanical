# 打印与配合：P2S 试打基线

2026-11-09。用户设备为拓竹 P2S，喷嘴 0.4 mm，预计层高 0.2 mm，材料为 PLA 或 PETG。
以下是试打起点，不是已经完成实物验证的工艺参数。实际耗材温度、流量、平台及冷却先使用对应材料配置并做校准。

## 起始切片设置

| 项目 | 起点 | 说明 |
|---|---|---|
| 层高 | 0.2 mm | 外观与时间折中；按耗材状态调整 |
| 墙层数 | 4 道 | 孔壁、支撑柱和直筋比全局填充率更依赖连续壁线 |
| 顶部 / 底部壳层 | 各 5 层 | 按 0.2 mm 层高约各 1 mm；检查实际切片结果 |
| 全局填充 | 20% Gyroid | 作为第一版试打，不宣称载荷验收完成 |
| 局部填充 | 先看预览；必要时 40～60% | 用于自攻柱、螺母座周围，不默认把整板加密 |
| 壁线宽度 | 先用切片器材料/喷嘴默认值 | 2 mm 筋厚不等于固定的壁线数量，需看路径有无薄缝 |

PLA 可先验证尺寸、拆装与形状；考虑 CAT 温升及车体振动，最终更倾向 PETG，但仍需确认工作温度、紧固保持和实际载荷。
PETG 也可能在持续夹紧下发生松弛，不能靠大扭矩补救；螺母和自攻结构均需试装。

## 两个件的打印朝向不同

- **CAT 连接件**：与外壳贴合的托板平面放在平台，四根柱子朝上。
  四向直筋从托板逐层生成。柱脚盘在最后形成，直筋之间仍有局部悬挑，应逐层检查，不仅看模型是否有斜面。
- **电池架**：建议底部向平台、电池腔口向上。不要套用 CAT 的倒置方向，否则会产生大面积跨空。
  底部两条扎带浅槽宽 6 mm，会形成短桥接；PETG 的桥接、下垂和槽口尺寸要检查。
- 第一版以少支撑为目标；是否完全免支撑由切片预览和试件决定。
- 贴合大平面优先用切片器的象脚补偿，别未经测量同时扩大孔并开启多套几何补偿。

## 已有间隙与未校准项

| 接口 | CAD 名义尺寸 | 目前含义 |
|---|---|---|
| M3 机牙通孔 | Ø3.3 mm | 对 Ø3 螺杆预留直径 0.3 mm；不是实测打印孔径 |
| 普通 M3 六角螺母窝 | 对边 5.8 mm | 对名义 5.5 mm 螺母预留对边 0.3 mm，约每侧 0.15 mm |
| CAT 螺母窝深度 | 2.6 mm | 对名义高 2.4 mm 螺母预留 0.2 mm；剩余夹持板厚 2.4 mm |
| 电池架螺母承托面 | 局部 Z=-1，电池承托面 Z=2 | 名义螺母顶低于电池承托面 0.6 mm，仍需核对实际螺母和螺柱长度 |
| CAT M3×10 自攻导孔 | Ø2.5、深 9 mm | 试配值；必须匹配实际自攻螺丝牙型、材料与扭矩 |
| 电池内腔 | 62.6×86.6 mm | 沿用原参考件，没有针对实际电池另加间隙；电池实物尺寸待核对 |

六个 CAT 外壳孔用普通 M3×10＋螺母；四个底板孔用 M3×10 自攻，这两种螺丝不可互换用途。
M3×10 普通螺丝头位于 CAT 壳内，PCB 下方净空尚未核对。

## 推荐先做的小试件

用同一台打印机、同一耗材、同一朝向和切片配置测试：

- 机牙通孔：Ø3.2 / 3.3 / 3.4 mm。
- M3 螺母窝：对边 5.6 / 5.8 / 6.0 mm，检查能装入且不会空转。
- 自攻导孔：可先试 Ø2.4 / 2.5 / 2.6 mm，按实际螺丝推荐值调整，不当作通用标准。
- 电池架 6 mm 桥接扎带槽与圆角槽口，检查下垂、毛刺及扎带通过性。

记录实测孔径、装入方式、是否开裂/滑牙、重复拆装结果。PLA 与 PETG 的结果分别记录，不共用未经验证的补偿。

## CAT 下一轮优化讨论方向

1. 先通过切片壁层与填充减重，保留当前用户要求的均匀 5 mm 托板。
2. 在不改变安装孔、八条通风槽、柱脚占地的前提下，讨论外轮廓圆角、筋根小圆角及孔口导入。
3. 检查倒置打印时脚盘扇区的悬挑，必要时仅对柱身—脚盘交界增加短过渡；四条直筋仍保持全高。
4. 若仍需明显减重，再讨论非受力区域的减重窗。它会改变当前整板外观，尚未授权默认加入，也不默认改成蜂窝。
5. 验证 CAT 抬高后的雷达视场、PCB 螺丝头净空、线缆和维护空间，再通过实物振动/紧固试验判断稳定性。

本轮只记录这些方向，CAT 几何保持用户已认可的直筋版。
