# FreeCAD 入门笔记

> 面向本项目的目标：在 R3 底盘上装配传感器/设备，定制亚克力板与 3D 打印支架。
> 建议用 **FreeCAD 1.0.x 稳定版**（内置 Assembly 装配工作台，不用再装插件）。

## 1. 十个核心概念

1. **文档 (.FCStd)**：一个文件里可以有多个零件，树状面板（左上角"模型"标签）管理一切对象。
2. **工作台 (Workbench)**：顶部下拉切换。常用四个：
   - `Part Design` — 画实体零件（主流做法：草图 → 拉伸/挖切）
   - `Sketcher` — 画二维草图（画板子外形、孔位就在这里）
   - `Assembly` — 装配（1.0 起内置）
   - `Part` — 布尔运算、处理导入的 STP 等
3. **参数化**：每个尺寸都是参数，随时改数值模型自动重建。不要"画死"。
4. **Body（实体）**：Part Design 里一个 Body = 一个实体零件。一棵特征树从上到下依次执行（草图→拉伸→开孔…）。
5. **草图约束**：草图里用约束（水平、垂直、距离、重合…）把图形"完全约束"（变绿色），模型才稳。
6. **Pad / Pocket**：拉伸凸台 / 挖切——画完板子外形用 Pad 拉出 3mm 厚度；画孔用 Pocket 或直接拉伸圆。
7. **基准参考**：可以选中导入模型（如底盘）的边、面作为草图参考，孔位就能精确对齐底盘已有孔。
8. **Spreadsheet / VarSet**：建一个参数表（板厚、孔距…），草图尺寸引用它，改表即改全模型。
9. **装配 Joint**：Assembly 工作台用"接头"把两个零件的面/边对齐（重合、同轴、距离…），不是手动拖。
10. **Python 控制台**：`视图 → 面板 → Python 控制台`，所有操作都有对应 Python 命令，可脚本化批量建模。

## 2. 鼠标导航（默认 CAD 风格）

| 操作 | 动作 |
|---|---|
| 旋转 | 中键拖动（或 Shift+右键拖） |
| 平移 | Ctrl+中键拖（或中键+右键一起按） |
| 缩放 | 滚轮 |
| 框选/点选 | 左键 |
| 导航风格切换 | 右键 → 导航（可选 Blender/Touchpad 等） |

不习惯就在 3D 视图里**右键 → 导航样式**直接切换（或 `编辑 → 首选项 → 显示 → 导航`）。
**用过 Blender 就选 `Blender` 风格**：中键旋转、Shift+中键平移、滚轮缩放，和 Blender 一致。
（另有 `Maya-Gesture`、`Touchpad`、`CAD` 等可选，随时可换，不影响模型。）

## 3. 第一个零件：亚克力板（完整流程）

1. 新建文档 → 切到 **Part Design** → 创建 Body → 创建 Sketch，选 XY 平面。
2. 画矩形外形；用"距离约束"标长和宽 → 草图全绿（完全约束）→ 关闭。
3. 选中草图 → **Pad** 拉伸，厚度 3 mm → 得到板子。
4. 在板子顶面新建草图画孔：画圆 → 约束直径（M3 螺丝孔画 3.4 mm，预留间隙）→
   约束圆心到板边的距离。 → **Pocket** 穿透。
5. 孔多的话用 **线性阵列 (Linear Pattern)** 或**极阵列**，只约束一个孔。
6. 保存到 `parts/` 目录。

进阶：把"板厚、长宽、孔距"放进 Spreadsheet，尺寸表达式里写 `Spreadsheet.板厚`，
改表一键改模型。

## 4. 装配流程（Assembly 工作台）

1. 新建文档存到 `assemblies/`，切到 **Assembly** 工作台。
2. `插入组件` 把 `models/…_utf8.stp`（底盘）和 `parts/` 里的零件插进来。
   - STP 导入后是实体，可以直接参与装配。
3. 第一个插入的零件设为 **固定 (Grounded)**——把底盘固定，其他件往它上面装。
4. 创建 **Joint**：选支架的孔圆柱面 + 底盘的孔圆柱面 → "同轴/重合"接头，自动吸附对位。
5. 全程不要在树里手动改零件坐标（那是"假装配"，一改模型就散）。

## 5. 输出给加工

### 亚克力板 → 激光切割（DXF）

1. 选中板子顶面 → `文件 → 导出` → 选 **DXF**（平面轮廓直接导出）；
   或用 **TechDraw** 工作台生成工程图再导 DXF（更正规，可带标注）。
2. 导出前检查：单位是 mm；孔是闭合圆。发给淘宝切割店时说明厚度（常用 3 mm 亚克力）。
3. 文件放 `output/dxf/`。

### 支架 → 3D 打印（STL）

1. 选中 Body → `文件 → 导出` → **STL**（或 3MF）。
2. 切片软件（PrusaSlicer / OrcaSlicer / Cura）打开切片打印。
3. **公差经验值**：配合孔放大 0.2~0.4 mm（M3 孔画 3.2~3.4）；
   受力卡扣壁厚 ≥ 2 mm；悬空 > 45° 要加支撑。
4. 文件放 `output/stl/`。

## 6. 本项目实操建议

- 装配时**先用底盘模型量孔位**：`Part` 工作台的测量工具（或 `测量 → 距离`），
  选两个孔边即可读中心距。和 `f407/docs/chassis_hole_map.svg` 的解析结果互相印证。
- 传感器支架优先"抄孔"：在支架草图里引用底盘孔的边线（外部几何工具），
  底盘改了支架跟着改。
- 每次大改前**另存新版本**（FCStd 不支持增量合并，git 只能存二进制快照）。
- 遇到模型报错：看树里哪个特征带感叹号，通常是改了上游尺寸导致草图参考丢失，
  双击该特征重新选参考。

## 7. 乱码问题备忘

- 原因：ZW3D 导出的 STP 把中文名按 GBK 原始字节写入，FreeCAD 按 UTF-8 读 → 乱码。
- 修复：`tools/stp_gbk_to_utf8.py` 按 GBK 解码后以 **UTF-8** 写回（默认模式）。
- ★**不要用 `--mode x2`**：FreeCAD 的 STEP 导入器不解析 `\X2\` 转义，会原样
  显示 `\X2\56DB...` 字符串。x2 模式只在发文件给别人用 SolidWorks/UG 打开时才用。
- 自己用 FreeCAD 建的模型导出的 STP 不会有此问题（FreeCAD 按 UTF-8 导出）。
