## 三、装配步骤（自下而上）

**0. 预处理**：打印件去毛刺；锚孔用 Ø3 钻头手捻过一下；打印 1:1 纸样贴板核对锚孔位置（装配路线图阶段4 门槛）。

**1. 层间铜柱**：6×M3×50 立到底板 (±50,80)(±50,−10)(±50,−90) 孔上，从**底板下方**穿 M3×6 拧入铜柱。

**2. 层 1 设备**：
- 设备塔：底座落位 → 8×M3×10 从板底穿入，防松螺母在底座顶面拧紧 → **铜柱从底座底面沉头孔拧入（M3×6）**：F407 位 M3×18×4、TB6612 位 M3×5×4、RT8279 位 M3×4×4 → 三块板各自放上铜柱，M3×6 从板面拧入（**F407 最后**）
- 电池：磁吸片贴底板 (0,−64) 区域，电池直接吸上
- TOF后支架：2×M3×10+螺母锚定 (±26,−118.4) → TOF-F2 前脸贴墙（前脸是纯平板，光学凸起对中央通窗）→ **2×M1.6×4 从墙后 Ø1.8 过孔拧进模块 M1.6 螺纹孔**
- 前传感器支架B：4×M3×10 锚定 (±8,96.6)(±23.5,96.6) → TOF-M 上舌片，2×M2.5×8+螺母

**3. 上层板**：对准 6 铜柱放上，6×M3×6 从板面拧入铜柱顶。

**4. 层 2 设备**：
- LubanCat转接板：10×M3×10+防松螺母（螺母在板顶，壳底净空内容纳）
- 外壳：4×M2.5×6 单头铜柱**公头先拧进外壳底部螺纹孔**（手拧即可）→ 外壳落到转接板对孔 → 4×M2.5×12 从转接板**底面沉头孔**拧入铜柱母头
- 雷达转接板：4×M3×10+螺母锚定 (±21,40)(±26,80) → 雷达整机（耳朝车尾）落位 → **4×M4×10 从板底沉头孔拧入底座螺纹孔 (±17, 45.8/84.2)** → 2 面耳墙各 1×M3×12 辅助 → 相机上板前缘墙，4×M2.5×8+螺母

**5. 接线**：电机→TB6612；编码器→F407；电池→RT8279→F407；雷达/相机/TOF→LubanCat。

## 四、拆卸与改装指南

| 要拆什么 | 怎么拆 | 备注 |
|---|---|---|
| **整层上层板** | 板面 6 颗 M3×6 → 整层（含外壳/雷达/相机）一起抬走 | 日常检修层 1 首选，层 1 全暴露 |
| 换电池 | 直接拔（磁吸） | 无需任何工具，电池已前移到 (0,−64) |
| LubanCat 外壳 | 转接板**底面** 4×M2.5×12（沉头孔内）→ 外壳连铜柱整体拿下 | 铜柱留在壳上不用动 |
| 雷达 | 板底 4×M4×10（+耳墙 2×M3×12）→ 雷达整体向上取出 | 无需动外壳 |
| 相机 | 雷达板前缘墙后 4×M2.5 螺母 → 相机单独下 | |
| TOF-M / TOF-F2 | 舌片后 2×M2.5 螺母 / 墙后 2×M1.6 | |
| F407 / TB6612 / RT8279 | 板面各 4 颗 M3×6 → 单板取下，铜柱留塔上 | F407 在最上层先拆；机牙拧铜柱，不限拆装次数 |
| 设备塔整体 | 板底 8 颗 M3 螺母 → 整塔端走（板卡可留塔上） | |
| 任一打印转接件 | 对应锚点螺母 → 单件取下，互不牵连 | 所有件独立锚定，无串联 |

**改装/扩展预留**：
- 设备塔右侧（x≈20~48, y≈17~32）与右后角有空位，可加小板卡（避开锚孔 ≥4.8mm）
- LubanCat 转接板中部还有未用现成孔（(±13,−32)、(±8,−8) 等），扩锚或挂小件都行
- 想恢复"相机在层 1"：方案 A 的 `test1.FCStd` 与 `前传感器支架A.FCStd` 仍在磁盘（未入 git），随时可打

**螺丝复拧注意**：塔上板卡、外壳、雷达全部走"机牙螺丝 ↔ 铜柱螺纹"，**不限拆装次数**；唯一例外是 M1.6×4（TOF-F2 前脸螺纹孔），反复拆装建议不超过 3 次，松了就点胶。
