# 当前两层机械设计

更新：2026-11-03。用户已确认采用两块相同的现有铁底板搭两层，层间铜柱先按 **50 mm** 做可调模型。
铁板保留原轮廓和孔型，打印件仅用于设备与铁板的转接和支撑。

## 固定的分层

| 层 | 设备 | 当前几何依据 |
|---|---|---|
| 第一层 | 前 TOF、后 TOF、C30D MCU、电池 | TOF 厂家模型、C30D 装配基线、用户指定电池托架参考 |
| 第二层 | CAT、雷达、相机 | CAT 厂家外壳、雷达厂家模型、IMX415 V1R1 尺寸图 |

当前入口为 `assemblies/two_layer.FCStd`。C30D 独立安装基线保留在 `assemblies/c30d_on_chassis.FCStd`。
后续改动只维护本两层方案。

## 钢板与高度

两块铁板的几何完全相同，均从底盘源模型提取，模型厚度 **1.5 mm**。

| 基准 | Z / mm |
|---|---:|
| 第一层铁板顶面 | 1.5 |
| 第二层铁板底面 | 51.5 |
| 第二层铁板顶面 | 53.0 |
| C30D PCB 底面 | 7.5 |
| C30D 元件最高点 | 19.77 |
| CAT 外壳底面 | 66.0 |
| CAT 外壳顶面 | 112.6 |
| 雷达底部 | 86.0 |

`Params.layer_gap` 控制层间高度：上层钢板、上层全部设备、层间铜柱及电池高度预算随之联动。
层间铜柱在模型中显示六个**候选位置**，尚未确认实车孔位占用，不代表安装孔已定案。

## CAT 连接件

CAT 位于第二层后部。托板紧贴外壳底面，默认厚 3 mm，复制外壳的 **8 条通风槽、6 个固定孔**。
下面为四个 Ø10 的局部落脚，铁板接触范围由四处落脚决定，避免用大面积整板贴住铁板。
落脚高度默认 10 mm；铁板到 CAT 底面总高 13 mm。

当前四脚只是结构概念，**未开铁板锚孔**。外壳孔径、螺丝/螺母、打印补偿以及最终脚位要在选孔阶段一起确定。

## 雷达与相机

雷达放在第二层前部，概念转接架抬高 33 mm（顶板 3 mm、局部支撑 30 mm）。
这一高度用于让原模型上部扫描头的最低点也高于 CAT 壳顶；几何读数见检查报告。
它仍属于第二层设备的局部支架，不增加主层板。该净空只针对金属壳体，CAT 外部天线和线缆尚未布置。

厂家雷达 STEP 中原有弯曲线缆与机身分开保存，线缆默认隐藏，后续按实际接线重新布置。
雷达机身固定方式、支架受力和实际扫描视场仍需核对。

相机位于第二层前缘，朝 +Y。板轮廓为 29×31.25 mm，孔距 23×24 mm，来自 V1R1 尺寸图。
板厚 1.2 mm、镜头 Ø12×8 mm 仅为占位假设，**不得据此加工镜头配合件**。
相机支架仅有板卡安装孔示意，尚未选择铁板锚孔。

## 第一层 TOF 与电池

前 TOF-M 朝 +Y，后 TOF-F2 朝 −Y。TOF-F2 厂家 STEP 是曲面组合而非闭合实体，当前用作参考及空间检查。
前后 TOF 固定件尚未设计，光学方向依厂家模型光学面判断，完整视场与装拆空间仍待核对。

电池托架以 `models/电池托架参考.step` 为准。参考文件含原配层板与托架两个实体；只采用托架，原配层板不作为 R3 钢板。
托架外形约 66.6×117×12 mm，当前横置在第一层后部，内腔和夹持结构保留。
参考件四个原孔为 Ø3.4、孔距 26×105 mm，**这些原孔尚未调整成 R3 固定孔**。

参考 STEP 没有完整电池实体。托架承托面为 Z=3.5 mm，到第二层板底面有 48 mm；
预留 2 mm 间隙后，电池本体高度上限为 **46 mm**。模型中的线框只表示高度预算，不是实物电池模型。
该高度预算尚未扣除穿出上层铁板的螺栓、螺母及线缆空间。实际电池高度、出线及取出方式需后续确认。

## 当前验证与未决项

`output/two_layer/two_layer_checks.json` 记录钢板几何一致性、层间参数联动、CAT 通风槽、雷达扫描头高度、设备占位等检查。
三维实体有效或占位不相交，并不等于已完成加工、紧固或实物验收。

下一阶段按用户要求讨论实际可用孔、禁用孔和底面螺母空间，再定 CAT 落脚、层间铜柱、电池和各传感器固定件。
电池实高、线缆、视场、维护、承载、振动与打印配合尚未验证，当前没有最终打印包。
