## 2. 安装定位（核心结论）

- **安装位 = 底盘中部"树莓派孔组" 58×49mm**（C30D 角孔孔距同为 58×49，四角直接对齐）
- 底盘四角孔坐标（原点=底板中心 Ø20 大孔，**+Y = 车头方向**）：

| 角 | X (mm) | Y (mm) | 底盘孔径 |
|---|---|---|---|
| 左后 | -21.05 | -29.79 | M2.5 |
| 右后 | 36.95 | -29.79 | M2.5 |
| 左前 | -21.05 | 19.21 | M2.5 |
| 右前 | 36.95 | 19.21 | **M3** |

- **五金**：M2.5 铜柱 ×4 + M2.5 螺母 + 垫片（C30D 孔为 D3.0，穿 M2.5 螺杆有 0.5mm 间隙，垫片压紧即可）
- **垫高**：≥6mm（让开板底元件与走线；验证模型按 6mm）
- **方向**：验证装配为 0°（模型坐标与底盘同向，**无需旋转**）。若电机走线不顺，可整板转 180°——58×49 矩形中心对称，孔位仍对齐

## 3. FreeCAD 复现步骤（装配同事按此操作）

1. 新建文档，导入 `models/R3mini四驱小车底盘（无悬挂）_utf8.stp`
2. 导入 `models/C30D-V2.2_2026.04.20.stp`
3. 选中 C30D 零件 → 属性 **Placement → Position**：
   - **X = 29.18，Y = -11.52，Z = 5.81**（Z 对应 底板顶面 1.5 + 6mm 铜柱；若改铜柱高度 H，则 Z = H − 0.19）
   - Rotation 保持 0
4. 验证：俯视四角孔同心；执行干涉检查，C30D 与底板/轮组无碰撞
5. 对照件：直接打开 `models/c30d_on_chassis.FCStd` 即上述结果的成品

> 自动化脚本：`freecad/tools/align_c30d_on_chassis.py`（freecadcmd 无头运行，自动生成装配 FCStd + 对齐误差报告 `output/align_c30d_report.txt`）

## 4. 电气接线（装配时按此预留走线与开口）

| 连接 | 说明 |
|---|---|
| 电源输入 | 12V 电池 → 电源口（红正黑负，**≤17V，禁反接**） |
| 电机 ×4 | **实车现行接法：A口=右后、B口=左后、C口=左前、D口=右前**。⚠️与官方接线图不同——固件已做端口重映射匹配此接法，**就按此接，不要按官方图改** |
| 串口3（Type-C） | → 鲁班猫 5 USB（ROS 通信，115200） |
| 串口1（Type-C） | 烧录/调试口，留在手能够到的位置 |
| Type-C 5V 供电口 | → 鲁班猫 5 供电（与舵机共 5V/3A 预算） |
| SWD 调试（H2 排针左上 2×2） | pin20=3V3、pin18=GND、pin16=SWDIO(PA13)、pin14=SWCLK(PA14) |
| 使能开关 | 保持可触及（电机总开关，断开则 PWM 归零） |

## 5. 旧件为什么退役（一块顶三块）

C30D 单板集成：STM32F407VET6 主控 + 4×AT8236 电机驱动（单路 ≤1.3A）+ 板载 5V/3A、3.3V 电源（替代稳压模块）+ 4 路编码器接口 + ICM20948 陀螺仪 + OLED + CAN。三件套的功能全部被覆盖，接线大幅减少。

## 6. 安全注意

- 板子**不得直接放金属面**，四角必须用绝缘铜柱固定后上电
- 上电前核对电源极性；触碰板子前释放静电
- 电机禁止长时间堵转（单路 ≤1.3A，4 路总 ≤5A）
