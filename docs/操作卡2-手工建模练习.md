# 操作卡 2：手把手手工建模（不走脚本）

> 目标：亲手建出 F407 简化板和摄像头简化板，把"草图→约束→拉伸→开孔"这套
> 参数化流程跑一遍。脚本 `tools/make_simple_parts.py` 只作为兜底/尺寸速查，不作主线。

## 练习 1：F407 简化板（40.89 × 68.59 × 1.6，4×Ø3.2 孔）

> 尺寸已实锤（芯路城官网封装解析 + 尺寸图互证），详见 `docs/ref/F407板尺寸来源.md`。

1. **新建文档** → 立刻另存为 `parts/F407板_练习.FCStd`（先存名，防崩丢）。
2. 切 **零件设计** 工作台 → 工具栏 **创建实体(Body)** → 再点 **创建草图** → 选 XY 平面。
3. 用矩形工具画个大概的矩形（尺寸先乱画没关系）。
4. **加约束**（这是精髓）：
   - 选中一条横边 → **水平距离约束** → 输入 `40.89`
   - 选中一条竖边 → **垂直距离约束** → 输入 `68.59`
   - 选中左下角顶点 + 原点 → **重合约束**（把板钉在原点）
   - 全绿 = **完全约束**，状态栏会提示"完全约束"
5. **关闭草图** → 选中草图 → **Pad(凸台)** → 长度 `1.6` → 得到板。
6. **四个角倒圆** R3：选中板顶层 → 草图画圆角，或对实体棱边倒圆角。
7. **开 4 个孔**：选中板**顶面** → 新建草图 → 画一个圆：
   - 直径约束 `3.2`（固定孔规格 3mm，留量）
   - 圆心到两条边的距离约束：横向边距 `3.05`、纵向边距 `3.05`
     （即孔距 34.79 × 62.48，孔正好在圆角圆心上）
   - 关闭 → **Pocket(凹槽)** → 贯穿
   - **镜像**出另外三个（或再画三个约束同样的边距）
8. **试一下参数化**：回草图把 40.89 改成 45，模型跟着变。这就是"改数不改图"。

## 练习 2：摄像头简化板（29 × 31.25，四角 R3，4×Ø2.5）

同样的流程，多练两个点：

- **圆角**：草图里直接画"圆角矩形"（Sketcher 的圆角工具倒四个角 R3），
  比拉完再倒角更干净、更好改。
- **4 个孔**：只约束**一个**孔，另外三个用 **线性阵列 / 镜像** 复制。
  之后只改第一个孔的位置，四个一起动。
- **占位件**：镜头座、FPC 座另外建草图 Pad 上去，高度按实测（镜头座实际更高）。

## 必须养成的三个习惯

| 习惯 | 原因 |
|---|---|
| 草图**必须完全约束**（变绿） | 不约束的图一改尺寸就乱跑 |
| 先画外形，再开孔，再倒角 | 顺序反了会导致特征参考丢失（树里出现感叹号） |
| 树里的特征**重命名** | 三天后回来你能看懂哪一步是啥 |

## 建完之后

把建好的件插进 `assemblies/` 的装配文档验证：外形对不对、孔位对不对、高度够不够。
不对就回去改草图数字——**这就是参数化建模的价值，不用重画**。
