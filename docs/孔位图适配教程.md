# 孔位图适配已有 3D 模型 · FreeCAD 操作手册

> 目标：给底盘上的器件（F407 / TOF / 雷达……）做打印转接板，孔位全部从模型投影，不手输。
> 环境：FreeCAD 1.1（`D:\tools\FreeCAD 1.1\bin\freecad.exe`）

## 〇、三条铁律（这次翻车的根源）

1. **孔位绝不手输坐标** —— 用"外部几何"从实物模型上投影（G X）。模型动，孔跟着动，永远不错位。
2. **每个尺寸都要能溯源**：模型圆柱面 / 官方图纸 / 卡尺实测，三者至少占二。只有模型且模型是"外观模型"时（孔可能是画的），必须有图纸或实物交叉验证。
3. **打印前过两道关**：1:1 纸样贴实物比对 → 1mm 薄试孔片。正式件最后打。

## 一、准备工作台

| 操作 | 按键/菜单位置 |
|---|---|
| 新建文档 | Ctrl+N |
| 导入 STEP/STP | 文件 → 导入（Ctrl+I），选文件 |
| 切换工作台 | 顶部下拉框 → **Part Design** |
| 视图 | `1`前视 `2`顶视 `3`右视 `0`等轴测；`V F` 全图适应；`V S` 对准选中物 |
| 鼠标（CAD 风格） | 滚轮缩放 · 中键拖动平移 · Shift+中键旋转 |
| 隐藏/显示选中对象 | 空格 |

## 二、把器件摆到正确位置

1. 左侧树里选中器件 → 左下"属性"面板 → **Placement → Position** 输 x/y/z。
2. 要旋转：Placement → Axis & Angle。
3. 摆好后在树里右键器件 → 锁定/记下 Placement 数值。

> 器件相对底盘的位置就是你的设计输入。比如"TOF 前脸贴车尾"就是在这里定下来的。

## 三、建转接板（核心：外部几何投影孔位）

以"给 F407 做铜柱转接板"为例：

1. **建 Body**：Part Design 工具栏 → `Create body`（圆柱+方块图标）。
2. **建草图**：树里展开 Body → 选中 `XY_Plane` → 工具栏 `Create sketch` → 视图自动转正俯视（歪了按 `Q P` 对齐）。
3. **画板轮廓**：按 `G R`（矩形）→ 点第一角 → **直接键盘输长度 → Tab → 输宽度 → 回车**。
4. ★**投影孔位（关键动作）**：
   - 按 `G X`（外部几何）→ 到 3D 视图里**点器件上的孔边圆**（可以转视角去点，视图操作不中断命令）→ 圆以**紫红色**投到草图里。
   - 底盘上的成品孔也一样投影——锚定孔位就是这么来的。
5. **画你的孔**：`G C` 画圆 → 圆心落在投影圆上（自动吸附，或事后按 `C` 加"重合"约束）→ 按 `D` 标直径。
   - 通孔孔径速查：M3 螺丝/铜柱位 **Ø3.2**；M2.5 → Ø2.8；M1.6 → Ø1.8。
6. **收尾**：所有线变黄/绿（全约束）才算定死。点任务面板"关闭"或按 `Esc` 退出草图。

## 四、拉伸成板 + 打孔

- **Pad（凸台）**：选中草图 → 工具栏 Pad → 厚度 3mm → OK。
- **通孔两个办法**：
  - 草图画了孔圆：再选中 → **Pocket（凹槽）** → Type 选 `Through all`。
  - 更推荐 ★**Hole（打孔）工具**：点一个面 → 选孔心位置 → 对话框里选 ISO Metric / M3 / **Clearance**（过孔）；要沉头就选 **Counterbore** 填 Ø5.5 深 2.5（藏 M3 螺丝头）。

## 五、铜柱怎么用（结构见上面剖面图）

铜柱不用建模，板上只要做孔：

| 位置 | 孔 | 干什么 |
|---|---|---|
| 转接板锚定孔 | Ø3.2 通孔 | M3×10 + 防松螺母锁到底板 |
| 铜柱位 | Ø3.2 通孔 + 底面沉头 Ø5.5×2.5 | M3×6 从板底拧入铜柱，头藏起来 |
| 板卡孔 | 板卡自带 Ø3 | M3×6 从板卡面拧入铜柱顶 |

铜柱长度 = 你要的间距（塔上 F407 用 M3×18 就是这么来的）。

## 六、三道验证关（不过不打印）

1. **同文档目视**：转接板和器件放同一文档，转视角看孔对孔；Part 工作台 → 菜单"检查几何"（BOP check）全绿。
2. **1:1 纸样**：TechDraw 工作台 → `Insert Page using template` → `Insert View`（选转接板，俯视图）→ 标孔径孔距 → 导出 PDF → **打印选"实际大小/100%"** → 贴实物比对。打印后拿尺子量一下纸上的 50mm 标尺。
3. **试孔片**：把 Pad 厚度临时改 1mm 导出切片先打一片（几分钟几克料），孔位全部对上了再改回 3mm 打正式件。

## 七、快捷键速查（Sketcher 内）

| 键 | 功能 |
|---|---|
| `G L` / `G C` / `G R` | 直线 / 圆 / 矩形 |
| **`G X`** | **外部几何（投影别的模型的边/孔）** |
| `G N` | 实线 ↔ 构造辅助线切换 |
| `D` | 标注尺寸（智能约束） |
| `C` | 重合约束（锁圆心/端点） |
| `H` / `V` | 水平 / 竖直约束 |
| `E` / `S` | 相等 / 对称约束 |
| `M` | 工具模式切换（画折线/矩形时） |
| `Esc` | 退出当前命令 |
| `Q P` | 视角对齐草图平面 |

> 忘了就悬停工具栏按钮，提示里有快捷键。工作台切换：顶部下拉框。

## 八、这次的教训清单（2026-10-19，TOF 后支架）

- 手填的孔位错了 1.5mm —— 铁律 1
- 外观模型里 z11/z16 的"4 个孔"是 0.1mm 装饰环带，不是孔 —— 铁律 2（圆柱面面积 <1mm² 的都是假的）
- M1.6 vs M2 规格错 —— 官方图纸一句话就定了（2-M1.6），以后先找图纸
- 没打纸样就下单 —— 铁律 3
