# 操作卡 4：实操第一课（从零搭起装配 + 支架 + 亚克力板）

> 跟着做，每步都有"做到位了应该看到什么"。做完一步再往下。

## 第 0 步：开工设置（只做一次）

1. 导航风格：3D 视图右键 → **导航样式 → Blender**
2. 单位：`编辑 → 首选项 → 常规 → 单位` → 选 **mm**
3. STEP 编码：`编辑 → 首选项 → 导入导出 → STEP` → **CodePage** 选编码（底盘文件选 GBK）
4. 打开面板：`视图 → 面板 → 模型`（左侧树）+ `属性`（左下）

## 第 1 步：新建装配文档

1. `文件 → 新建`
2. **立刻** `文件 → 另存为` → `assemblies/R3装配_v1.FCStd`
   （先存名再干活，这是最重要的习惯）

## 第 2 步：导入底盘并固定

1. 切到 **装配** 工作台
2. `文件 → 导入` → 选 `models/R3mini四驱小车底盘（无悬挂）_utf8.stp`
3. 导入后如果名字乱码 → `宏 → 宏… → fix_step_names → 运行`
4. 树里选中底盘 → 点 **切换固定（Grounded）** 图标（图钉样子）→ 底盘变基准，不再移动
5. 按 `V, F` 看全图

✅ 自检：拖动其他东西时底盘纹丝不动，且树里底盘旁有图钉标记。

## 第 3 步：分组（相当于"层"）

FreeCAD 没有图层，用**组**分类：

1. 树里右键文档名 → **创建组** → 改名 `参考件`（底盘放进去，拖进去即可）
2. 再建两个组：`支架模块`、`亚克力板`
3. 选中组按**空格** = 整组隐藏/显示（做内部结构时天天用）

✅ 自检：隐藏"参考件"组时底盘消失，其余不受影响。

## 第 4 步：什么时候才需要"复制底盘"

**只有一种情况要复制**：你想在底盘上开新孔（验证新孔位可行）。

- 做法：树里选中底盘 → `编辑 → 复制` / `粘贴`（或 Ctrl+C/Ctrl+V）→ 改名 `底盘_改装版`
  → 在这个副本上用 Part Design 开孔。
- **只是当参考**就别复制：原件 + Joint 对齐即可，复制反而会让你分不清哪个是准的。

> ⚠️ 复制出来的底盘要放"参考件_副本"组里，别和原件混在一起。

## 第 5 步：新建支架模块（3D 打印件）

1. 切 **零件设计** → **创建实体(Body)** → 改名 `支架_A`
2. **创建草图** → 选一个平面（贴着底盘安装面）
3. ⭐**引用底盘孔位**（关键技巧）：
   草图里点 **外部几何**（External Geometry，虚线图标）→ 在 3D 里点底盘上的孔圆边
   → 该孔的投影出现在草图里（紫红色线，不可改，只能参考）
4. 以它为圆心画圆 → 直径约束（M3 孔画 **3.4**，留间隙）
5. 画支架外形（矩形/圆角矩形），加尺寸约束 → **草图变绿**
6. 关闭 → **Pad** 拉伸出厚度（3D 打印常用 4~6mm）
7. 需要螺丝沉头？再建草图挖 **Pocket**

✅ 自检：改底盘孔的位置，支架的孔跟着动——说明引用成功了（不是抄的数字）。

## 第 6 步：亚克力板 + 孔位

1. 同样 **零件设计 → 创建实体** → 改名 `亚克力板_主控层`
2. 先建参数表（强烈推荐）：
   `工具 → 创建变量集(VarSet)` 或建 Spreadsheet → 加变量 `板厚 = 3.0`
   → Pad 长度里填 `VarSet.板厚`（改表即改模型，2/3/5mm 随便试）
3. 草图画板外形 → Pad `VarSet.板厚`
4. 孔位：**同样用外部几何**引用底盘/板卡的孔边，画同心圆 → Pocket 穿透
5. 别忘了三类孔（操作卡3 提过，最容易漏）：
   - **设备安装孔**（对 F407 34.79×62.48 / 摄像头 23×24）
   - **过线孔**（走线穿过板子）
   - **扎带孔**（固定线束，2 个一组）
6. 圆角：外形四角倒 R3~R5（激光切割不会应力集中，也更好看）

✅ 自检：把板厚改成 5，模型和孔位关系不变，只是变厚。

## 每节课收尾三件事

1. **Ctrl+S 保存**（每 10 分钟一次）
2. 树里特征**全部重命名**（不然三天后看不懂）
3. 有问题看**报告视图**（`视图 → 面板 → 报告视图`），红色字是报错线索
