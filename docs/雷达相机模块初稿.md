## 雷达主架与朝向

- 上层铁板顶面为世界 Z=53，主架承托面约 Z=86，总垫高33 mm。
- 源雷达绕 Z 转 -90°，再平移 `(0,55,118.921927)`；**安装耳及90°盲区朝车尾/世界-Y/CAT**。
- 铁板四个锚孔：后排 `(±20,29.35351)`，前排 `(±20.85965,84.07281)`，已由用户接受。
- “19.26”是前孔靠内侧的边缘，实际孔中心 X=±20.85965。
- 主架用 M3×10 自攻螺丝，从铁板下方穿入打印柱；导孔Ø2.5、深9是试配值，不是已校准标准。
- 前脚为邻孔 `(±26,81.61340)` 留避让：底部4.2mm高范围 R3，以上保留 R1.8 螺杆走廊。
  自攻导孔邻近避让处的几何剩余壁厚约1.45mm，实际抗开裂与紧固保持需要试件验证。
- 底部两孔承压垫按源模型转向后的位置设计：局部 `(±25.5,8.3)`；普通M3固定方式仅作结构预留，实物孔数/螺纹和允许入孔深度仍待核对。
- 主架直接承重；相机调整或更换不应改变雷达的安装姿态。

## 三面孔带与相机插接

承托台下沿沿前、左、右围成U形，后方敞开供雷达接线。
每面6个直边矩形孔，**孔6.4×5 mm、节距10 mm**，合计18孔。
孔口圆角在当前内核的局部操作中失败，初稿保留直边；不能把图形称为已完成打印修边的圆角孔。

相机模块使用两个宽5.6mm的挂钩，插入后下落定位；矩形面限制转动。
孔带下方另有M3锁紧孔，普通M3×10从框内侧向外拧入相机座螺母窝，防止模块上抬脱钩。
相机座下方落在铁板上，不额外占用铁板固定孔。底脚约97.8%的名义面积落在钢板实心区，其余为现有孔洞。
孔带上的所有位置不意味着可同时装多个相机：相邻外壳、螺丝、工具和线缆空间仍需逐一排布检查。

当前双钩退出动作检查为：取下防脱螺丝→上抬2mm→前移退出，再抬离。
这只是刚体几何路径，不包含手指、线缆或打印卡紧误差。

## 相机外壳与固定

已按用户意见将大开口保护框替换成“小盒体＋后盖”。

| 项目 | 当前暂定值 |
|---|---|
| 盒体外廓，不含侧面调角凸台 | 34.2×36.2 mm |
| 带后盖的前后总深 | 18.5 mm |
| 内部平面空间 | 31×33 mm，比图纸PCB每侧留约1mm；也容纳后螺母支承 |
| 侧壁厚度 | 约1.6 mm |
| 前壁 / 后盖厚度 | 各2 mm |
| 镜头开口 | Ø18，中心按图像位置暂估，离PCB底边19.5 mm |
| PCB厚度 / 原四孔直径 | 1.2 / 2.5 mm，仅占位 |
| 镜头包络 | Ø12×8 mm，仅占位 |
| 后盖排线口 | 16×3 mm，仅占位 |
| PCB/外壳固定通道 | Ø2.8，按M2.5方向预留；后窝对边5.3；实际规格、头型与长度待测 |

前方螺丝通道与四角PCB孔同轴，前后支承柱夹持板角；后侧六角窝用于放螺母，金属件与板背面留隔离距离。
不能用普通M3螺丝硬穿目前按Ø2.5假设的相机孔。暂不随这一版提供确定的相机紧固件采购规格。
镜头尺寸、排线、器件突出和孔径未测，用户允许先做暂估设计；外壳实际配合需修改参数后验证。
背面螺母入口和排线口仍开放，镜头口也留量，**只能说减少裸露与进灰，不能宣称密封防尘或防水等级**。

相机壳通过两侧M3俯仰轴连接到挂接座。当前显示-10°下俯；确定视角后再替换为一体固定角度件。
不再保留被替代的独立T槽或大开口保护框方案作为当前模型。

## 当前检查结论与限制

- 四个零件的基本BRep检查为单实体、闭合，原生时间线无错误。
- 当前-10°展示姿态的零件互相避让、底板/雷达/CAT的主要干涉检查通过。
- 角度测试到-20°时，相机壳与相机座有约17.35mm³干涉；**不能宣称可连续调整到-20°**。
- 主架STEP详细BOP检查有导出曲线与曲面的诊断警告，已保留计数；它与“基本实体闭合”是不同层面的检查。
- 自攻孔与螺母配合、支架刚度/振动、实物尺寸、完整视场、线缆和打印支撑均未验证。
- 不修改当前已经在打印的电池架/CAT文件；原有后TOF与电池盒干涉继续保留。
