## 两个独立来源，互证一致

| # | 来源 | 内容 |
|---|---|---|
| 1 | `f407/materials/size.png`（官网尺寸图，本目录有副本 `F407mini_尺寸图.png`） | 固定孔直径 3mm；孔距横向 34.79 / 纵向 62.48；板宽 40.89 / 板高 68.59 |
| 2 | `f407/materials/STM32F407VET6-Mini开发板封装/STM32F407VET6-Mini开发板封装.pcbdoc`（**Altium ASCII 格式**，可直接文本解析） | 全部焊盘/板框坐标，见下 |

解析方法：pcbdoc 按 `|RECORD=` 分割，字段 `X=..mil|Y=..mil|HOLESIZE=..mil`，mil×0.0254=mm。

## pcbdoc 解析结果（权威值）

**板外形**：40.894 × 68.591 mm（板框 Track：x 76.2~117.094，y 76.2~144.791），四角 R3.053

**安装孔 4×**：孔径 **3.2mm**（规格称 3mm，按 3.2 建模留量），焊盘 5×5mm 方形

| 孔 | X (mm) | Y (mm) |
|---|---|---|
| 左下 | 79.253 | 79.253 |
| 左上 | 79.253 | 141.737 |
| 右下 | 114.041 | 79.253 |
| 右上 | 114.041 | 141.737 |

- 孔距：横向 **34.788**、纵向 **62.484**（与尺寸图 34.79 / 62.48 完全一致）
- 孔中心距板边 3.053mm（正好在圆角圆心上）

**排针**：左右两侧 **双排 2×22**，间距 2.54mm，双排排距 2.54mm
- 左侧行 X：77.597 / 80.137；右侧行 X：113.157 / 115.697
- Y 跨度 83.825~137.165（22 针，跨 53.34mm），相对板居中
- 孔径 0.9mm（排针孔）→ **可用插针式固定：底板装 2×22 排母**

**其他**：SWD 4P（板顶）、Boot0 5P、TFT/OLED 接口、SD Card 座（板底）、Micro USB（页面标题"Micro口"）
