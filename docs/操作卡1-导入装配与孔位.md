## 2. 导入多个 STP 到同一文档

1. 新建文档 → **先保存**为 `assemblies/R3试装.FCStd`（养成先存名的习惯）。
2. `文件 → 导入` → 在文件对话框里 **Ctrl 多选**：
   - `models/R3mini四驱小车底盘（无悬挂）_utf8.stp`
   - `models/TB6612四路驱动稳压模块（D24A）_utf8.stp`
   → 两个模型一起进当前文档。（也可以直接从资源管理器**拖进 3D 窗口**。）
3. **跑一次修复宏**：`宏 → 宏… → fix_step_names → 运行`（见 §0.5）。
4. 左侧模型树里会出现各零件对象，名字应为正常中文。
5. 看不到模型就按 `V, F`。

## 3. 调整各零件之间的位置

### 方法 A：手动粗摆（用于先摆个大概布局）

- **属性面板法**：点选对象 → 左下角属性面板展开 `Placement` →
  改 `位置` 的 x/y/z（平移）、改 `旋转` 的轴和角度。精确、可控。
- **变换法**：选中对象 → 右键 → **变换 (Transform)** → 出现彩色手柄：
  拖箭头=沿轴平移，拖圆环=绕轴旋转 → 摆好按 Esc 确认。
- **放置对话框**：`编辑 → 放置…` 可输入增量（如"绕 Z 转 90°"），点"应用增量"。

### 方法 B：Joint 精确对位（正式装配用这个）⭐

1. 切到 **Assembly** 工作台 → 工具栏"新建装配"，把树里的零件拖进 Assembly 容器。
2. 选中底盘 → 右键/工具栏 **"切换接地 (Grounded)"** —— 基准件固定不动。
3. 点 **"创建接头 (Joint)"**，类型常用两种：
   - **Fixed（固定）**：两个面完全贴合锁定（板子贴铜柱端面）
   - **Cylindrical（圆柱）**：同轴但可转动/滑动（螺丝穿孔、铜柱插孔）
4. 依次点选：第一个零件上的面/圆柱面 → 第二个零件上的面/圆柱面 → 确定。
   两个零件自动吸附对位。
5. 装错了：树里删掉那个 Joint 重做即可，零件本身没坏。

> 练手目标：把 TB6612 的某个安装孔与底盘前部孔位做 Cylindrical 接头，看自动对位效果。

## 4. 对比孔位（测量工具）

1. 切到 **Part** 工作台（或 1.0 顶部工具栏直接有）→ **测量 (Measure)**。
2. **量孔距**：Ctrl 加选两个孔的**圆边线** → 面板显示两个圆心距离 + 各自半径。
3. **量孔径**：选一个圆边 → 半径 ×2。
4. 核对清单：
   - 底盘孔中心距 vs 你的支架孔中心距 → 必须一致
   - 孔径 vs 螺丝：M3 螺丝 → 孔画 **3.2~3.4 mm**（预留间隙）
   - 与 `f407/docs/chassis_hole_map.svg` 的解析坐标交叉验证
5. **进阶（推荐）**：在支架草图里用 Sketcher 的**外部几何**工具直接引用底盘孔的边线
   画同心圆——孔位天然对齐，根本不用量。

## 5. 装螺丝 / 铜柱

**快速占位**（验证阶段够用）：
- Part 工作台 → 创建**圆柱**（螺丝杆）+ **六棱柱**（铜柱身），按实物尺寸改参数。

**正经标准件**：
- `工具 → 插件管理器` 装 **Fasteners** 工作台 → 直接生成国标 M3 螺丝/螺母/垫圈。

**装配固定**：
1. 铜柱外圆柱面 + 底盘孔内壁 → **Cylindrical** 接头（铜柱立在底盘上）
2. 亚克力板孔内壁 + 铜柱上段外圆 → **Cylindrical**（板子套上铜柱）
3. 板面 + 铜柱端面 → 如要锁死再补一个 **Fixed**
4. 螺丝同理：螺杆外圆 + 孔 → Cylindrical。

## 6. 常见卡点

| 症状 | 原因/解法 |
|---|---|
| 导入后一片空白 | 按 `V, F` 适配；检查单位是否 mm |
| 树里对象变灰 | 被空格隐藏了，选中再按空格 |
| 模型巨大/巨小 | STP 单位被误解为 m，删除重导并检查首选项单位 |
| Joint 选不中面 | 对象可能包在容器里，展开模型树点到实体再选面 |
| 装配越调越乱 | 别拖动零件坐标，删 Joint 重做；零件位置应由 Joint 决定 |
| 想从内部看 | 空格隐藏上层零件，或 Part 工作台用"剖切面 (Section Cut)" |
