## 阶段 2：装配演练

1. 新建 `assemblies/R3整车装配.FCStd`，切 Assembly 工作台。
2. 插入底盘 → 设为固定件（Grounded）。
3. 逐个插入 TB6612、自制板卡，用 Joint（同轴/重合）对位到底盘孔。
4. 底盘孔位坐标参照 `f407/docs/chassis_hole_map.svg`（STP 解析值）；
   装配时用测量工具抽查几个孔距，互相印证。
5. 目标：所有件不干涉、线能走、手能够到接线端子。

## 阶段 3：亚克力板 / 支架设计（边设计边装回来验证）

1. 在 `parts/` 建板/支架零件（Part Design，草图全约束）。
2. 孔位直接引用装配中底盘/板卡的边线（外部几何），不用手抄数字。
3. **每改一版就插回装配体验证**：干涉检查 + 拆装顺序是否合理。
4. 板厚参数放 Spreadsheet（亚克力 2/3/5 mm 都可能试）。

## 阶段 4：确认后才加工 ⛔ 前置门槛

全部满足才导出：
- [ ] 装配体无干涉（Section Cut 剖切检查内部）
- [ ] 孔位与实物复测一致（打印 1:1 纸样贴底盘比对，最便宜的验证）
- [ ] 螺丝刀/手操作空间够
- [ ] 走线路径想好（电源线 vs 编码器线分开）

然后：亚克力 → 导 DXF 到 `output/dxf/` 发切割；支架 → 导 STL 到 `output/stl/` 切片打印。
