# freecad — R3 小车机械改装项目

用 FreeCAD 做底盘的传感器/设备装配设计，定制亚克力板与 3D 打印支架。

## 目录结构

| 目录 | 用途 |
|---|---|
| `models/` | 导入的参考模型（STP）。原件不动，修复版放这里 |
| `parts/` | 自制零件（亚克力板、支架等）的 .FCStd |
| `assemblies/` | 装配体 .FCStd（底盘 + 自制件 + 传感器） |
| `output/dxf/` | 导出给激光切割的 DXF 二维图 |
| `output/stl/` | 导出给 3D 打印的 STL/3MF |
| `tools/` | 辅助脚本（如 STP 乱码修复） |
| `docs/` | 学习笔记、操作卡 |

## 工作流程

**现有模型转换导入 → 缺失件自制 → Assembly 试装 → 亚克力板/支架边设计边装回验证 → 全部确认后才加工打印。**
详细阶段与验收门槛见 `docs/装配路线图.md`。

## 关键文件

- `models/R3mini四驱小车底盘（无悬挂）_utf8.stp` — 乱码已修复的底盘模型，装配用这个
- `models/TB6612四路驱动稳压模块（D24A）_utf8.stp` — 乱码已修复的驱动板模型
- `tools/stp_gbk_to_utf8.py` — 乱码修复脚本（GBK→UTF-8）
- `tools/fix_step_names.FCMacro` — ⭐**真正好用的方案**：本机 FreeCAD 1.1 dev 不认任何文件层编码，
  导入 STP 后跑一遍此宏（宏→宏…→运行），三种乱码通吃。已装入 FreeCAD 宏目录
- 孔位参考资料（在 f407 项目）：
  - `f407/docs/chassis_hole_map.svg` — 底盘孔位精确坐标图（从 STP 解析）
  - `f407/docs/hardware.md` §7 — 孔位结论（TB6612 无直装孔组等）

## 自制件（2026-10-19 v3 两层结构）

| 文件 | 说明 |
|---|---|
| `parts/上层板.FCStd` | 层2 亚克力 2mm，20 孔（铜柱×6 / LubanCat×4 / 雷达平台腿×4 / 传感支架×6）|
| `parts/雷达平台.FCStd` | 84×124×2 桥式平台，架在 LubanCat 上方（腿 M3×35）|
| `parts/设备塔.FCStd` | 层1 前部转接座（3D 打印）：拧底盘 42×42 孔组，载 TB6612 + F407 架高 18mm |
| `parts/摄像头支架.FCStd` | IMX415 前缘支架（3D 打印）|
| `tools/build_two_layer.py` | 零件生成脚本（含孔位自动校验）|

Z 向：底板 1.5 → 设备塔(F407 顶 ~37.5) → M3×50 铜柱 → 层2 板 51.5 → LubanCat M3×12 垫高出风(65.5~85) → 桥腿 M3×35 → 平台 88.5 → 雷达 ~110。
层1：电池(0,−88) 扎带、设备塔(0,63)、RT8279(48,60)、MPU6050 贴 (0,−5)；TOF-M 朝前 / TOF-F2 朝后。
